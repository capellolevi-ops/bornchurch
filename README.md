# Born Church Launchpad

Crie um site completo, moderno, responsivo e profissional para uma igreja evangélica chamada **Born Church**.



## Estilo



* Design moderno e elegante.

* Cores predominantes: preto, branco e dourado, com detalhes em azul escuro.

* Aparência semelhante aos sites de igrejas internacionais.

* Animações suaves ao rolar a página.

* Layout totalmente responsivo para celular, tablet e computador.

* Carregamento rápido.

* SEO otimizado.

* Interface limpa e intuitiva.



## Página Inicial



Criar uma seção principal (Hero) com:



* Logo da Born Church.

* Título grande:

  **"Bem-vindo à Born Church"**

* Subtítulo:

  **"Um lugar para nascer de novo, crescer na fé e viver o propósito de Deus."**

* Dois botões:



  * "Conheça a Igreja"

  * "Planeje sua Visita"



Adicionar uma imagem ou vídeo de fundo de uma igreja durante um momento de adoração.
